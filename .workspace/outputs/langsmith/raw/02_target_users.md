# Langsmith Target Users

## Questions
- Who are the core users, buyers, and day-to-day operators?
- How do high-value users differ from low-value users?
- Which user segments are not a good fit yet?

## Findings
Core users are developers, data scientists, and AI teams who build and deploy language model applications. High-value users are those with complex workflows requiring customization and monitoring. Non-fit segments might be casual users or those without technical expertise.

## Evidence Buckets
- User personas
- Usage data
- Customer interviews
