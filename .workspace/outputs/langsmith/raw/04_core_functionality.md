# Langsmith Core Functionality

## Questions
- Which features are core, and which are just nice to have?
- Will users form a repeatable workflow around the product?
- Are there any obvious capability gaps?

## Findings
Core features include language model orchestration, monitoring, and debugging tools. Nice-to-have features might be advanced analytics or collaboration tools. Users likely form repeatable workflows around model testing and deployment. Gaps could be in integrations or UI polish.

## Evidence Buckets
- Feature list
- User feedback
- Product roadmap
